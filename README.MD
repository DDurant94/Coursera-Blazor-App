# EventEase — Event Management Application

**Author:** Daniel Durant

## Overview

EventEase is a Blazor WebAssembly application built for corporate and social event management. The application enables users to browse upcoming events, view detailed event information, and register for events — all while tracking real-time seat availability per event.

## Features

- **Event Listings** — Browse a catalog of upcoming events displayed as interactive cards, each showing the event name, date, location, category, and current availability.
- **Event Details** — Navigate to a dedicated detail page for each event, displaying the full event description, date, time, and location.
- **Registration** — Register for any event by submitting a simple form. The application prevents duplicate registrations and confirms successful sign-up.
- **Live Availability** — Each event card displays the number of registered attendees, remaining spots, and a color-coded progress bar indicating capacity status.

## Technology

- **Framework:** Blazor WebAssembly (.NET 10)
- **Language:** C#
- **Styling:** Bootstrap 5
- **Architecture:** Component-based UI with service injection and in-memory state management
